# 타워 디펜스 작업 목록

pygame으로 만드는 타워 디펜스 게임. 작업은 세 가지다.

1. 게임 코드
2. 맵 에디터
3. 맵 제작

게임과 맵 에디터는 같은 맵 파일 형식을 쓴다. 그래서 **맵 형식을 가장 먼저 정한다.**

---

## 0. 공통: 맵 파일 형식

- [x] 맵 파일 형식: JSON (`.json`)
  - `tiles`: 문자열 배열. 문자열 하나가 한 행, 글자 하나가 타일 하나
  - 그 외 키(예: `name`, `start_gold`, `lives`)는 필요할 때 추가. 에디터는 `tiles`만 고치고 다른 키는 그대로 둔다.
- [ ] 타일 문자 정의

  | 문자 | 타일 | 설명 |
  |---|---|---|
  | `.` | `BuildableTile` | 타워를 지을 수 있는 칸 |
  | `#` | `RoadTile` | 적이 지나가는 길 |
  | `S` | `SpawnTile` | 적이 나오는 곳 (`RoadTile` 상속) |
  | `G` | `GoalTile` | 적이 도착하는 곳 (`RoadTile` 상속) |

- [ ] 맵 규칙 정하기
  - `S`와 `G`는 각각 하나씩
  - 길은 `S`에서 `G`까지 한 줄로 이어짐 (갈림길 없음)
  - 모든 줄의 길이가 같음
- [ ] 타일 크기, 맵 크기(가로×세로 칸 수) 정하기

예시 (`maps/test.json`):

```json
{
  "tiles": [
    "............",
    "S####.......",
    "....#.......",
    "....#..####G",
    "....#..#....",
    "....####....",
    "............",
    "............"
  ]
}
```

## 추천 순서

1. 타일 문자와 맵 규칙 확정
2. 맵 클래스와 로더 → 화면에 맵 그리기
3. 적 이동 → 타워 → 웨이브 → UI (여기까지 하면 게임이 돌아감)
4. 맵 에디터
5. 에디터로 맵 제작

맵 에디터는 이미 있으므로, 테스트 맵은 에디터로 만들거나 JSON을 직접 써도 된다.
